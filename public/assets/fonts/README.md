# Fonts

Galmuri9 / Galmuri11 / Galmuri14 (v2.40.3) by Lee Minseo (quiple),
https://github.com/quiple/galmuri — SIL Open Font License 1.1 (see
`Galmuri-OFL.txt`). The `.woff2` files are the unmodified upstream release
files from the `galmuri` npm package; they are not subset or edited because
the license reserves the font name "Galmuri" for unmodified versions.

Each family is a pixel font with its own design grid (9px / 11px / 14px).
Render it at integer multiples of that size to stay crisp — use
`pixelFont()` from `src/i18n/fonts.js` instead of picking sizes by hand.
